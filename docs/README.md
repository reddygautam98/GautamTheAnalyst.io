# Gautam Reddy portfolio (v17)

Static site. No frameworks, no build step needed to deploy.

- Pages: index, about, services, projects, resume (web view only), contact, samples/index
- assets/style.css, assets/site.js, assets/vendor/lenis.min.js (smooth scroll, MIT, bundled so there is no CDN dependency)
- One Google Fonts request (IBM Plex Sans/Mono, Source Serif 4)
- Light and dark theme (follows the system setting, remembers the choice)
- Deploy: upload the contents of this folder to GitHub Pages (keep the folder structure)
- Run locally: `python -m http.server 8000`

## What v17 adds
- 3D hero scene with pointer-follow depth, 3D tilt cards, scroll reveals, animated counters, keyword marquee
- Animated BPMN / swimlane / ERD / sequence / data-pipeline diagrams behind every section (generated by flows.py)
- Project cards show each repository's GitHub preview image (`opengraph.githubassets.com/1/reddygautam98/<repo>`). If an image cannot load, a designed placeholder shows instead.
- Everything animated switches off under "reduce motion" system settings

## Editing
`python3 build.py` regenerates all 7 HTML pages from build.py (copy, links, keywords) and flows.py (diagrams).
The recruiter keyword lists are KW_ROW1, KW_ROW2, META_KW and ROLES_ROT at the top of build.py.
