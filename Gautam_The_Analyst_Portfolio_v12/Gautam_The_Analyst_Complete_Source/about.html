Operating principles

How the work stays trustworthy.

The habits behind the documents: clear scope, visible evidence and a handover people can use.

// 01

Evidence before opinion

Findings, assumptions and limitations are kept separate, so guesses are never presented as facts.

// 02

Scope you can point at

Agreed deliverables and acceptance criteria define what “done” means before work begins.

// 03

Traceable by design

Requirements connect to stories, tests and decisions, so any change has a visible impact.
